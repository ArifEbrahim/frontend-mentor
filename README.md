# Frontend Mentor Challenge Solutions

This project is a portfolio of solutions to Frontend Mentor challenges, built as a single-page React app.

## Tech Stack
- React 19 + TypeScript
- Vite
- Tailwind CSS
- React Router

## Usage
1. Install dependencies: `pnpm install`
2. Start dev server: `pnpm dev`
3. Navigate to `http://localhost:5173/`
